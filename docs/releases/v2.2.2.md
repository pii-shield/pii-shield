# PII-Shield v2.2.2 Release Notes

PII-Shield v2.2.2 is a patch release with one detection fix: file names and relative paths with an extension (`report.csv`, `config.yaml`, `src/main.go`, `invoice_2024.xlsx`) are no longer redacted as entropy. There are no breaking changes and no configuration changes.

## Highlights

- Scanner: a new structural safe rule recognises file-name shaped tokens, so Python tracebacks, build logs, `git status` output, upload logs and diff bodies keep the one token that makes the line actionable.

## Bug Fixes

### Bare file names and relative paths redacted as entropy (#189)

`isPath` only recognised absolute Unix paths and Windows paths. A relative path or a bare file name had no structural rule and was scored on entropy, where `.`, `/` and `_` add class bonus on top of the letters and digits: `report.csv` scored 3.62 against the 3.6 default threshold, `config.yaml` 3.96, `src/main.go` 3.96, `invoice_2024.xlsx` 4.73. In practice:

```
Traceback: File "app/services/billing.py", line 42, in charge  ->  Traceback: File "[HIDDEN:entropy:…]", line 42, in charge
ERROR main.go:42 failed to open report.csv                    ->  ERROR main.go:42 failed to open [HIDDEN:entropy:…]
```

The new `isFileName` rule accepts tokens made of `[A-Za-z0-9._/-]` only (no `=`, `+`, `:`, `@`), with a non-empty stem and a last `.`-separated extension of 1 to 5 alphanumerics starting with a letter. The shape is deliberately narrow: JWTs and SendGrid-style keys have long base64 segments after their last dot, IPv4 addresses and version strings end in digits, e-mails carry `@`, URLs are handled earlier. `./x`, `../x` stay with `isPath`; `//`, `..`, dot-files with an empty stem (`.gitignore`) and extensionless names (`Dockerfile`, `Makefile`) do not match. No threshold change.

Values in a sensitive-key position (`api_key=….key`, `password=secret.txt`) are still redacted: the key rule runs before the safe rules. The accepted trade-off, documented in code: a secret-shaped stem with a short extension in free text (`Zq8vN3pL7xR2wT9yB4mK6.txt`) is treated as a file name.

Evidence for the change: regression tests, the frozen labeled corpus with no new deviations, 15 s of fuzzing, and an alternating micro-benchmark against the previous release showing no measurable cost (the rule exits early on tokens without a dot).

## Breaking Changes

No breaking changes. No salt, credential, or configuration changes are required. Default-behaviour change to be aware of: tokens shaped like a file name with an extension are no longer redacted by the entropy scorer.

## SDK Changes

`@aragossa/pii-shield-wasi` 2.2.2 (npm) and `pii-shield-wasi` 2.2.2 (PyPI) ship the rebuilt WASM kernel with this rule. SDK APIs are unchanged.
