# PII-Shield v2.3.1 Release Notes

PII-Shield v2.3.1 is v2.3.0 with one unused function removed. The v2.3.0 tag published the SDKs, the container images and the Helm charts, but its GitHub release (binaries and `checksums.txt`) never ran: the release workflow lints the whole module, found `isValueLiteral` left unused by #312, and skipped GoReleaser. v2.3.1 carries the same scanner, CLI, charts and SDKs as v2.3.0; see [v2.3.0](v2.3.0.md) for what changed since v2.2.8.

## Changes since v2.3.0

- **The unused `isValueLiteral` is removed (#321).** No behaviour change: its one caller had already moved to the `valueLiterals` set in #312.
- **The pull-request lint checks the whole module (#321).** `only-new-issues` is off in `ci.yml`, so a function left unused by a change fails the pull request, not the release.

## Artifacts

- GitHub release: binaries and `checksums.txt` for v2.3.1 (v2.3.0 has none).
- Container images: `2.3.1`, `2.3`, `latest`. The `2.3.0` images are the same code.
- SDKs: `@aragossa/pii-shield-wasi` 2.3.1 (npm) and `pii-shield-wasi` 2.3.1 (PyPI). The 2.3.0 packages are the same kernel; upgrading is optional.
- Helm charts 2.3.1, published on the merge of the release pull request.

## Upgrade Notes

```bash
helm repo update
helm upgrade pii-shield pii-shield/pii-shield --version 2.3.1
helm upgrade pii-shield-operator pii-shield/pii-shield-operator --version 2.3.1
```

```bash
npm install @aragossa/pii-shield-wasi@2.3.1   # Node
pip install --upgrade pii-shield-wasi==2.3.1  # Python
go get github.com/pii-shield/pii-shield/v2/pkg/scanner@v2.3.1  # Go
```

Binary checksums (`checksums.txt`) and container image tags are published on the GitHub release page; see `docs/release-verification.md` for the verification steps.
